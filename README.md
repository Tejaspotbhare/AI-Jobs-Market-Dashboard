AI Jobs Market Dashboard | Power BI

📊 Project Overview
An interactive Power BI dashboard created to analyze the AI job market, explore job opportunities, and understand in-demand skills and hiring trends.

🎯 Objectives
- Analyze AI-related job postings.
- Explore job roles, companies, and locations.
- Identify in-demand skills.
- Understand salary and experience requirements where available.
- Present insights through interactive visualizations.

🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX

✨ Key Features
- Job market analysis
- Job role and company analysis
- Location-wise job opportunities
- In-demand skills analysis
- Salary and experience analysis, where available
- Interactive visuals and filters

🎥 Dashboard Demo

`AI Jobs_Market Dashboard.mp4`

📁 Project Files
- `ai jobs.pbix` — Power BI dashboard file
- `AI Jobs_Market Dashboard.mp4` — Dashboard demonstration video

🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Explore the available visuals and filters.

Practiced data cleaning, data transformation, DAX calculations, and interactive dashboard development using Power BI.
